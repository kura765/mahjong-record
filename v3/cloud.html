麻雀対局記録サイト v3.0

クラウド試験版 — ルーム・閲覧共有・半荘スナップショットの検証用。現行の対局入力画面とは未統合です。

1. Supabase 接続

Supabase の Project URL と Publishable / anon key を入力してください。secret / service_role key は絶対に入力しないでください。接続情報はこのブラウザにのみ保存されます。

2. メールでログイン

メールに届くログインリンクを開いてください。同じブラウザで戻るとログインできます。

保存済みの半荘

    バックアップの取り込み

    既存の半荘は同じ内容ならスキップし、内容が違えば一括で中止します。途中で失敗しても一部だけ保存されることはありません。元の記録は変更しません。

    安全性について

    招待リンクは参加権限を持つ秘密情報です。公開しないでください。参加にはメール認証が必要です。ルーム作成者のみ半荘を書き込めます。参加者は閲覧専用です。この試験版では複数人の同時編集・自動同期を提供しません。
